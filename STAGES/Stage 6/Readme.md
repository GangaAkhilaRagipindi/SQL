## Stage 6: Database Programmability
Automating business logic directly inside the database engine.
* **Stored Procedures:** Reusable SQL code blocks with input/output parameters
* **User-Defined Functions (UDFs):** Scalar and Table-Valued functions
* **Triggers:** Automated execution (BEFORE, AFTER, INSTEAD OF) on data modifications
* **Cursors:** Iterative row-by-row processing (and why set-based operations are preferred)
