## Stage 1: Fundamentals & Core Commands
The foundations focus on retrieving, filtering, and organizing data, along with understanding the core sub-languages of SQL.
**SQL Command Subsets:
  DCL (Data Control Language):** GRANT, REVOKE
   DDL (Data Definition Language):** CREATE, ALTER, DROP, TRUNCATE
   DML (Data Manipulation Language):** INSERT, UPDATE, DELETE
   DQL (Data Query Language):** SELECT
   TCL (Transaction Control Language):** COMMIT, ROLLBACK, SAVEPOINT
Data Retrieval Basics:** SELECT, DISTINCT, WHERE, ORDER BY, LIMIT / TOP
Filtering & Operators:** AND, OR, NOT, IN, BETWEEN, LIKE, Wildcards (%, _)
Data Types & Constraints:** PRIMARY KEY, FOREIGN KEY, NOT NULL, UNIQUE, CHECK, DEFAULT
